# libGDX Android Game Template
## About

A basic libGDX game template (for Android).

## Building
### Prerequisites

- Android SDK
- Android NDK

### Building the APK

```shell
# Unix
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
```
